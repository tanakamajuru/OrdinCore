# Security testing record — OrdinCore

An internal vulnerability assessment and penetration test (VAPT) of OrdinCore was carried out
against the codebase and the live production system. Findings from the exercise were triaged and
remediated internally; fixes are reflected in the application's commit history.

This record exists to confirm that security testing of this kind has taken place and that findings
were acted on, without reproducing the technical detail of the exercise here.

**Status:** VAPT completed; findings patched.
